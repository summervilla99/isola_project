# Asset provenance

- Island, trees, flowers, houses, avatar and furniture: original procedural geometry authored for ISOLA in `src/components/world-scene.tsx`.
- Landing illustration, archive book/frame/bottle illustrations: original CSS in `src/app/globals.css`.
- App icon: original SVG in `public/icon.svg`; PNG variants rasterized from the same source.
- Village, club interior, club guard, and capybara character illustrations in `public/capy-world/`: generated for this project with OpenAI ImageGen and converted to WebP. These are original project assets, not copied from another game.
- Directional walking frames in `public/capy-world/walk/`: generated with OpenAI ImageGen from `capy-hero-v1.webp`, then extracted from the pose sheets into six transparent WebP frames. Prompt direction: preserve the exact character identity and costume while rendering separate front three-quarter, right-facing side, and rear three-quarter walking poses with alternating feet on a transparent background. The side frames were regenerated to keep both poses facing the same direction.
- 3D village art in `public/capy-world/real-3d/`: `sunset-sky.webp`, `palm.webp`, `club-facade.webp`, and `cottage-facade.webp` were generated for this project with OpenAI ImageGen, then optimized to WebP. Prompt direction: cinematic sunset over open sea; transparent cutout tropical palm; Mediterranean seaside club and cottage facades with terracotta roof, warm windows, flowers, and no environmental background. These are 2D details placed in a 3D scene.
- `docs/art-direction/capybara-story-world-keyframe-v2.png` is an OpenAI ImageGen art-direction keyframe made from the current in-game screenshot. Built-in generation mode was used. Final prompt direction: transform the existing scene into a premium stylized-realism Mediterranean storybook island at golden sunset; preserve the seaside club, walkable plaza, capybaras and wide gameplay camera; add cream stucco, terracotta, bougainvillea, lanterns, lush rolling grass, irregular rocky shoreline, turquoise foam, dimensional palms and natural warm/cool lighting; exclude UI, logos, humans, flat billboard vegetation, barren ground and plastic materials. It is a production reference, not a runtime background.
- `public/capy-world/village-v3.webp` is the optimized runtime environment plate generated with OpenAI ImageGen in built-in mode from the approved keyframe. Final prompt direction: recreate the same 16:9 Mediterranean sunset club plaza as a clean character-free playable environment; preserve the cream-stucco club, terracotta roof, glowing magenta-and-amber entrance, bougainvillea, stone plaza, turquoise sea, beach, palms, flowers and warm lanterns; leave a broad unobstructed central walking area; use coherent premium stylized-realism materials and natural golden-hour lighting; include no characters, UI, logo, words or watermark. The 1672×941 output was converted to a 444 KB WebP for the initial world screen.
- `sand-light.webp` and `sand-normal.webp` derive from Poly Haven `aerial_beach_01` and `coast_sand_02` respectively; `stone.webp`/`stone-normal.webp` from `cobblestone_01`; `wood.webp` from `wooden_planks`; `plaster.webp` from `plastered_wall_02`; `roof.webp` from `roof_tiles`. These are resized WebP derivatives of [Poly Haven](https://polyhaven.com/) assets under its [CC0 license](https://polyhaven.com/license). Asset pages: [beach](https://polyhaven.com/a/aerial_beach_01), [sand](https://polyhaven.com/a/coast_sand_02), [stone](https://polyhaven.com/a/cobblestone_01), [wood](https://polyhaven.com/a/wooden_planks), [plaster](https://polyhaven.com/a/plastered_wall_02), [roof](https://polyhaven.com/a/roof_tiles).
- The club beat in `src/lib/club-beat.ts` is synthesized in the browser with Web Audio; no licensed track or third-party audio file is included.
- Interface icons: lucide-react, ISC license (see installed package).
- Typography: system fonts (Avenir Next / Apple SD Gothic Neo / Noto Sans KR when locally available; system-ui fallback). No external font requests.
- Sample archive comments are original illustrative text. Book/film titles and creator names identify works; cover art, film posters and whisky trademarks are not copied.

No third-party game assets or user-provided media are used. The 3D village includes the CC0 Poly Haven textures listed above.
