## 신고 처리

관리자만 Supabase의 reports를 확인한다. 클라이언트에 service_role을 제공하지 않는다. 필요 시 운영자 권한으로 대상 기록 또는 댓글을 숨긴다. 처리 상태·감사 기록이 있는 전용 관리자 화면은 후속 작업이다.

## 계정 삭제

`deletion_requests`는 사용자의 명시적 요청이다. 접수 즉시 API 접근을 차단한다. 운영자가 Supabase Auth에서 해당 사용자 계정을 삭제하면 FK cascade로 프로필·기록·관련 데이터가 제거된다. 방장은 먼저 방장을 이전하거나 마지막 멤버로 섬을 정리한 후 요청할 수 있다. 자동 삭제 작업은 아직 없다. 실제 운영 정책을 준비하기 전 이 기능을 법적 삭제 완료로 안내하지 않는다.

## 롤백

코드 롤백은 이전 커밋을 배포한다. 첫 migration의 역방향 DROP을 운영 DB에 실행하지 않는다. DB는 변경 전 백업으로 복구하는 별도 절차를 따른다. 이후 migration은 기존 데이터와 호환되도록 추가한다.
